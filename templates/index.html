Machine Learning Architecture

Complete breakdown of the unsupervised pipeline currently running on the server.

1. DATA LOADER & PREPROCESSING
  • OpenCV VideoCapture: Running in a background thread via capture_loop.
  • Haar Cascades: Extracts face bounding box using haarcascade_frontalface_default.xml.
  • Normalization: Converts face crop to 48x48 Grayscale, applies cv2.createCLAHE for histogram equalization to mitigate lighting bias.
2. GEOMETRIC FEATURE EXTRACTION
  • 64-Dimensional Vector: Extracts highly specialized spatial features.
  • Action Units (AU Proxies): AU12 (Smile), AU4 (Brow Lowerer), AU5 (Eye Widener).
  • Gradients: Tracks vertical and horizontal spatial differences to measure brow tension and jaw drops.
3. AUTOENCODER (DIMENSIONALITY REDUCTION)
  • Topology: 64 → 128 → 32 → 128 → 64 nodes.
  • Purpose: Reconstructs geometric features to squeeze the essence into a 32-dimensional bottleneck (Latent Space).
  • Implementation: sklearn.neural_network.MLPRegressor.
4. CLUSTERING & HEURISTICS
  • K-Means (K=7): Unsupervised clustering to locate 7 latent emotion states.
  • Dynamic Baseline: Uses an Exponential Moving Average (EMA) baseline to detect relative changes in brow tension and smile energy.

USER GUIDE
Click "INITIATE SCAN" to spin up the web camera. Ensure your face is clearly visible and well-lit. The system will establish a baseline for your resting face over the first 6 seconds. Smile naturally to trigger the 'Happy' state, or relax to trigger 'Calm/Neutral'.
